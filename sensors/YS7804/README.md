# YS7804

## FCC filing
FCC ID `2ATM77805`, listed by YoSmart as **"Outdoor Motion Sensor"**. See [fcc_filings/2ATM77805](../../fcc_filings/2ATM77805) for the full filing and [chip_identification.md](../../fcc_filings/2ATM77805/chip_identification.md) (confirms a [YL09](../../chips/YL09) chip). Weatherproof enclosure, two-board design (PIR sensor board + separate main/radio board on a ribbon cable) - similar general layout to [P7805](../P7805) but a distinct product.
