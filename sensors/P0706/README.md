# P0706

Sensor board design reused across multiple YoLink products (see [sensors/README.md](../README.md)). Confirmed via FCC filing to underlie the [YS7704](../YS7704) door sensor specifically.

## FCC filing
FCC ID `2ATM77704`, listed by YoSmart as **"Door Sensor"** (shared with YS7704 - same filing). See [fcc_filings/2ATM77704](../../fcc_filings/2ATM77704) for the full filing and [chip_identification.md](../../fcc_filings/2ATM77704/chip_identification.md) (confirms a [YL09](../../chips/YL09) chip).
