# Scripts

- `dump_partitions.sh` - dump ESP32 flash partitions from a full flash image using `show_partitions.txt`-style offsets
- `gwconfig_manipulator.py` - read/write a hub's `gwConfig` NVS entry (including computing `gwConfigMD5`)
- `key_finder.py` - search a binary for candidate key material
- `nvsjson2csv.py` - convert a parsed NVS `nvs.json` dump into CSV
- `test_common_baud.py` - probe a serial connection to determine baud rate (used on [P1606](../../hubs/P1606))
