# Chips

Components/modules present across multiple YoLink products, documented separately from full [sensors](../sensors) since they're shared building blocks rather than standalone products.

- [P0603](P0603) - daughter board present in all hubs (likely COTS)
- [YL09](YL09) - YoLink's custom SiP (STM32L0 + SX1276-family LoRa radio), present in almost all sensors
