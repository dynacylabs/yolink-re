# P1605

Teardown photos only so far (`V1.3`); no firmware dump or debug analysis has been performed yet. This is the hub YoLink briefly/prematurely listed for sale before it was ready - see the project writeup for that story.

## FCC filing
FCC ID `2ATM71605`, listed by YoSmart as **"Hub 3"** (model `YS1605-UC`, confirmed via the product label photo in the filing). See [fcc_filings/2ATM71605](../../fcc_filings/2ATM71605) for the full filing and [chip_identification.md](../../fcc_filings/2ATM71605/chip_identification.md) - the photographed board is silkscreened `P1605_V1.3` and uses a **MediaTek MT7628NN**, not an ESP32.

This filing covers P1605 only - see [P1606](../P1606) for why that hub, despite looking similar, is a different (Rockchip-based) device with its own unidentified FCC ID.
